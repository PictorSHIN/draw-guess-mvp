# 你演我猜（Heads Up 式派对游戏）

线下朋友局常备的猜词小游戏：手机横举到额头、屏幕面向队友，队友描述、举机者猜。靠**翻转手机**计分——猜对下翻、放弃上翻。纯前端 H5，打开即玩、离线可用、零后端。

---

## 1. 功能简介

### 定位
- **场景**：3 人及以上的线下聚会，即开即玩、轻竞技。
- **形态**：纯前端 H5 单页应用（`index.html` 一个文件承载全部逻辑 + 视觉）；题库分离为 `data/words.js`；本地 HTTPS 测试服务 `server.js`。
- **非目标**：不做账号、社交、排行榜、付费、联网对战。

### 已实现功能
| 模块 | 说明 |
|---|---|
| 主题选择 | **11 个主题**：明星名人、影视作品、动物世界、美食小吃、动作表演、职业身份、成语俗语、网络热梗、品牌商标、地点景点、二次元 |
| 题库 | 每主题 **200 词，共 2200 词**，零重复、零乱码；运行时按「易→难」自动三等分为 简单/中等/困难 三档 |
| 难度 | 简单 / 中等 / 困难，三选一 |
| 倒计时 | 档位（60 / 90 / 120s）+ 滑块自定义（30–180s），两者联动 |
| 开局仪式 | 3 秒倒数后开始 |
| 体感翻牌 | 下翻＝答对，上翻＝跳过；桌面/无授权时自动显示按钮兜底 |
| 实时反馈 | 整屏色块闪光（绿=答对/粉=跳过）+ 大字提示 + 震动 + 音效；题目入场缩放动画 |
| 倒计时冲刺 | 最后 10 秒倒计时变红脉动 + 进度条闪烁 + 每秒滴答声/震动 |
| 音效 | WebAudio 实时合成（答对叮咚、跳过噗、秒针、结束和弦），无外部资源 |
| 退出答题 | 答题页右上角「✕ 退出」，走结算页展示已答对/跳过统计 |
| 结算 | 大号答对数 + 「答对 X · 跳过 Y」+ 逐题回顾（对/过标记）+ 再来一局/回首页 |
| 全屏 | PWA「添加到主屏幕」独立全屏 + Android Fullscreen API + `100dvh` 动态视口 |
| 横屏适配 | 首页/结算页横屏左右分栏；竖屏进游戏时提示「请把手机横过来」 |

### 题库抽象层
题目获取统一走 `getWords(topicId, diffId)` provider，数据源为 `window.WORD_BANK`（`data/words.js`）。未来接入 AI 实时生成，只需替换该 provider 为 async 实现，上层游戏逻辑无需改动。

## 2. 核心功能触发逻辑

### 2.1 体感翻牌（重力加速度方案）
> 代码：`index.html` 中 `onMotion()` / `enableGyro()`

- **传感器**：使用 `devicemotion` 的 `accelerationIncludingGravity`，取**屏幕法线方向重力分量 `z`**。
  - 手机竖直举额头时 `z ≈ 0`；向前翻转与向后翻转 `z` 符号相反且干净，**不受欧拉角万向锁影响**（早期用 `deviceorientation` 的 beta/gamma 会在竖直姿态下方向判反/同号，已弃用）。
- **判定**：
  - `z > 5.5` → **答对**（下翻，屏幕朝下）
  - `z < -5.5` → **跳过**（上翻，屏幕朝上）
- **防连触三道锁**（避免一次挥动跳过多题）：
  1. **回中重新武装**：触发后 `armed=false`，必须「已解锁 **且** `|z| < 3.0`（摆回近竖直）」才重新武装。锁定期内即使回中也不武装。
  2. **切题锁定**：`state.locked` 在触发后锁 950ms（等翻牌动画结束）。
  3. **冷却间隔**：两次触发最小间隔 `COOLDOWN = 1100ms`（≥ 动画时长）。
- **权限**：iOS 13+ 需在用户手势内调用 `DeviceMotionEvent.requestPermission()`，故放在「准备好了」按钮点击时申请。
- **兜底**：不支持传感器 / 授权被拒 / 3 秒内无数据 → 加 `body.no-gyro` 类，显示屏幕「答对/跳过」按钮。

### 2.2 全屏展示
> 代码：`requestFs()`、`manifest.webmanifest`、head 中 apple-mobile-web-app 系列 meta

- **iOS**：靠 PWA「添加到主屏幕」→ 独立 standalone 模式，无浏览器外壳（iPhone 不支持 Fullscreen API）。
- **Android**：点「准备好了」时在用户手势内调用 Fullscreen API 隐藏地址栏。
- **通用**：`100dvh` 动态视口 + `overscroll-behavior: none` 适配地址栏收放。

### 2.3 音效（WebAudio 合成）
> 代码：`sfx` 模块

- 纯 `OscillatorNode` 合成，无外部音频文件：答对（上行叮咚）、跳过（下行噗）、秒针（方波短音）、结束（上行和弦）。
- iOS 要求手势内解锁 AudioContext，故在「准备好了」按钮里 `sfx.unlock()`。

### 2.4 游戏流程状态机
```
首页(设置) → 准备页(授权+说明) → 3秒倒数 → 游戏页(答题) → 结算页
              ↑ 返回                                  ↓ 再来一局(沿用设置)
              └──────────────────────────────────────┘
结算页 → 回首页(重新设置)
游戏页 →(✕ 退出)→ 结算页(展示已答对/跳过)
```
- **结算触发**：倒计时归零 / 题目抽完 / 点击退出，三者统一走 `endGame()`。
- **每局重置**：`startGame()` 重置 `state`（deck/idx/results/timeLeft/locked）与体感状态（`GY.armed`、`GY.lastFire`）。

### 2.5 题库切分与洗牌
> 代码：由 `WORD_BANK` 构建 `TOPICS`、`getWords()`

- 每主题 200 词按「易→难」排列，构建时三等分：easy = 前 1/3，mid = 中 1/3，hard = 后 1/3。
- 每局对选中档位做 Fisher-Yates 洗牌，保证单局不重复；题目抽完则提前结束。

## 3. 对话轮次与变更日志

> 按需求提出的先后顺序记录（同一轮可能包含多项改动）。

### R0 · 需求澄清
- 多轮问答确认基线：H5 网页应用、体感翻牌（下翻答对/上翻跳过）、单机轮流单人计分、档位+滑块倒计时、3 秒倒数、暗黑霓虹风。
- 题库由「实时 AI 生成」调整为「先内置静态题库、预留 AI 接口」。

### R1 · 输出 PRD
- 产出 `PRD.md`：背景目标、用户场景、功能需求、题库设计、技术方案、验收清单等完整文档。

### R2 · 初版原型 + 布局精简
- 生成 `index.html` 单文件原型，跑通「首页→准备→倒数→游戏→结算」全链路。
- 去掉所有 emoji 图标、副标题；移动端更极简。
- **游戏中题目字号改为自适应充满屏幕**（`clamp` + `vmin`），远处可读。

### R3 · 修陀螺仪不生效 + 横屏错乱
- 定位根因：移动浏览器读传感器**需 HTTPS 安全上下文**。新增自签名证书 + `server.js`（本地 HTTPS 服务，端口 8443）。
- 补全**横屏适配**：题字 vmin 双向撑满；竖屏进游戏提示旋转。
- 重写体感判定（首版：欧拉角开局校准中位 + 滞回）。

### R4 · 全屏展示
- 新增 PWA：`manifest.webmanifest` + `icon.svg` + Apple 全屏 meta；`requestFs()` Fullscreen API；`100dvh` 动态视口。
- 验证「添加到主屏幕」全屏可用。

### R5 · 布局与功能优化（第一批）
- 题库从每档 10 扩到每档约 30（共 360 词，含去重/清乱码）。
- **翻牌反馈更醒目**：整屏径向渐变闪光 + 大字弹跳 + 题目入场动画。
- **横屏左右分栏**：首页（左标题/右设置）、结算页（左分数/右回顾）。
- **加音效**：WebAudio 合成答对/跳过/秒针/结束音。
- **倒计时冲刺**：最后 10 秒红色脉动 + 滴答声。

### R6 · 布局与功能优化（第二批）
- 精简准备页文字（4 行 → 2 行核心信息）。
- **题库大扩充**：抽离为 `data/words.js`，扩到 **10 主题 × 200 词 = 2000 词**（参考主流猜词 App 高频分类）；provider 改为按难度三等分。
- **答题页隐藏底部按钮**：体感可用时纯靠上举/下举，仅无传感器时显示按钮兜底（`body.no-gyro`）。

### R7 · 放慢翻牌动画
- 翻牌闪光时长 0.55s → 1s，关键帧加入中段停留（30%~70%）；切题延迟 480ms → 950ms；闪光清除 550ms → 1000ms，三处时序同步。

### R8 · 新增二次元主题 + 退出按钮
- 新增「二次元」主题（题库达 **11 主题 × 200 = 2200 词**）。
- 答题页右上角新增「✕ 退出」按钮（比分移至左上避免重叠）。

### R9 · 修体感连触多题
- 定位根因：滞回**重新武装只看角度、不看锁定期**，动画期间偷偷 re-arm 导致连触。
- 修复：重新武装须「已解锁 + 回中」；新增 1100ms 冷却；回中阈值收紧；每局重置体感状态。

### R10 · 二次元题库重构
- 从「全是角色名」重构为**四维度混合**：著名角色(~80) + 经典名句/梗(~55) + 著名招式/动作(~35) + 著名作品/名词(~30)，更适合表演。

### R11 · 退出走结算
- 退出答题从「直接回首页」改为「走结算页」，复用 `endGame()`，展示已答对/跳过统计；顺带把 `.urgent` 冲刺样式清理统一到 `endGame()`。

### R12 · 修体感方向（上下举都判答对）
- 定位根因：`deviceorientation` 欧拉角在横屏竖直姿态下撞**万向锁死区**，方向判反/同号。
- **改用 `devicemotion` 重力加速度**：取屏幕法线重力分量 `z`，前后翻转符号干净翻转，方向判定稳定；保留防连触三道锁；权限/兜底同步切到 `DeviceMotionEvent`。

## 微信小程序开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目根目录（`project.config.json` 已指向 `miniprogram/`）
3. 在 `project.config.json` 中填入你的 **AppID**（测试可用测试号）
4. 编译 → 真机预览 → 横屏举额头测试体感翻牌

**服务类目**：工具 > 效率（提审按「聚会辅助工具」描述）

## H5 本地运行（原型）
```bash
node server.js
# 手机与电脑同一 WiFi，浏览器访问 https://<电脑局域网IP>:8443
# 首次证书告警选“继续访问”；进游戏点“准备好了”时允许动作传感器授权
# 推荐：iOS 用“添加到主屏幕”从图标打开，获得无浏览器外壳的全屏体验
```

## 已知事项 / 后续可选
- `cert.pem`/`key.pem` 为本地自签名证书，生产需换正式 HTTPS。
- 体感方向若个别设备相反，可对调 `onMotion()` 内两处 `answer()` 参数；灵敏度调 `GY.TRIG`。
- 预留能力：AI 实时生成题目（替换 `getWords`）、计分规则可配置、历史最高分、分队对抗、多设备联机。
